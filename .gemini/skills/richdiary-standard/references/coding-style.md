# Coding Style & Conventions

## Naming
- Follow [StyleShare Swift Style Guide](https://github.com/StyleShare/swift-style-guide).
- Use clear, descriptive names for variables and functions.

## Organization
- Use `// MARK: -` for code grouping (Properties, Init, Life Cycle, Func, etc.).
- Keep files small and focused on a single responsibility.
- Place ViewModels, ViewControllers, and Views in their respective sub-directories within a feature folder.
